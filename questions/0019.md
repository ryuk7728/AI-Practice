# 0019 Causal Self-Attention Head

## Problem

Create a PyTorch module that implements one head of causal scaled dot-product self-attention.

```python
class Head:
    def __init__(
        self,
        embedding_size,
        head_size,
        context_size,
        dropout=0.0,
    ):
```

The module receives tensors with shape:

```text
(batch_size, sequence_length, embedding_size)
```

Expected behavior:

- The output has shape `(batch_size, sequence_length, head_size)`.
- Separate bias-free learnable representations are used for attention matching and value aggregation.
- Attention follows standard scaled dot-product self-attention behavior.
- A position can use information from itself and earlier positions, but not from later positions.
- Different examples in a batch are processed independently.
- Attention dropout uses the probability supplied to the constructor.
- Dropout is active in training mode and inactive in evaluation mode.
- Sequence lengths up to `context_size` are supported.
- Gradients propagate through the input and learnable parameters.

## Learning Objectives

- Implement a single self-attention head.
- Understand causal information flow in sequence models.
- Track tensor shapes through attention computations.
- Apply scaling, normalization, masking, and dropout in attention.

## Examples

```python
attention = Head(
    embedding_size=12,
    head_size=4,
    context_size=16,
    dropout=0.1,
)
output = attention(x)
```

For an input with shape `(2, 8, 12)`, the output has shape `(2, 8, 4)`.

## Complexity Discussion

For batch size `b`, sequence length `t`, embedding size `e`, and head size `h`:

- Time complexity: `O(b * t * e * h + b * t^2 * h)`
- Space complexity: `O(b * t^2 + b * t * h)`
