# 0012 MNIST Tensor DataLoader Prep

## Problem

Prepare MNIST-style arrays for PyTorch training.

```python
def prepare_mnist_loaders(X, y, batch_size=32, test_size=0.2, random_state=42):
```

`X` and `y` are NumPy arrays.

`X` contains image features with pixel values in the range `0` to `255`. Its shape is `(num_examples, 784)`.

`y` contains integer class labels. Its shape is `(num_examples,)`.

The function should return:

```python
X_train_tensor, X_test_tensor, y_train_tensor, y_test_tensor, train_loader, test_loader
```

Expected behavior:

- Scale feature values to the range `0` to `1`.
- Split `X` and `y` into training and test sets.
- Use `test_size` and `random_state` for the split.
- Convert training and test features to floating point PyTorch tensors.
- Convert training and test labels to integer class-label PyTorch tensors.
- Create PyTorch datasets from the training and test tensors.
- Create data loaders from those datasets.
- The training data loader should use `batch_size` and shuffle batches.
- The test data loader should use `batch_size` and not shuffle batches.

## Learning Objectives

- Prepare image arrays for PyTorch.
- Create deterministic train/test splits.
- Convert NumPy arrays into PyTorch tensors.
- Use `TensorDataset` and `DataLoader`.
- Choose appropriate tensor dtypes for features and class labels.

## Examples

```python
outputs = prepare_mnist_loaders(X, y, batch_size=32)
```

The returned training and test feature tensors should contain normalized pixel values.

## Complexity Discussion

For `n` examples:

- Time complexity: `O(n)`
- Space complexity: `O(n)`
