# 0002 Softmax

## Problem

Compute the softmax of input `x`.

```python
def softmax(x):
```

The function should work for 1D or 2D NumPy arrays.

For a 1D input, return one probability distribution.

For a 2D input, compute softmax row-wise so each row becomes its own probability distribution.

The output values should be non-negative, finite, and sum to `1` across the relevant dimension.

## Learning Objectives

- Convert raw scores into probabilities.
- Work with 1D and 2D array inputs.
- Understand numerical stability.
- Reason about overflow prevention.

## Examples

```python
softmax([1, 2, 3])
```

should return probabilities where the largest input receives the largest probability and all outputs sum to `1`.

```python
softmax([[1, 2, 3], [3, 2, 1]])
```

should return a 2D array where each row sums to `1`.

For large values such as:

```python
[1000, 1001, 1002]
```

the function should still return finite probabilities.


## Complexity Discussion

For an input with `n` total values:

- Time complexity: `O(n)`
- Space complexity: depends on the chosen implementation
