# 0011 PyTorch Model Accuracy

## Problem

Compute classification accuracy for a PyTorch model.

```python
def compute_accuracy(model, X_test, y_test):
```

Helper code is available in:

```python
helpers/q0011.py
```

It provides:

```python
FixedClassifier
make_classification_batch
```

The function should evaluate the model on `X_test`.

The model output contains one score per class for each example. `y_test` contains only the correct class id for each example.

For each row of model output, determine the predicted class id and compare it against the matching value in `y_test`.

Expected behavior:

- The model is put in evaluation mode.
- Accuracy is computed without tracking gradients.
- The return value is a scalar PyTorch tensor.
- The accuracy value is the mean of correct predictions.

## Learning Objectives

- Evaluate a PyTorch model.
- Convert model output scores into predicted class ids.
- Compare predictions with target labels.
- Compute mean classification accuracy.
- Avoid gradient tracking during evaluation.

## Examples

```python
from helpers.q0011 import FixedClassifier, make_classification_batch
```
