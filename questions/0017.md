# 0017 Character-Level Text Data Split

## Problem

Prepare text for character-level language-model training and divide it into training and validation portions.

```python
def prepare_text_data(text, train_fraction=0.9):
```

Expected behavior:

- Every distinct character is represented by a unique integer ID.
- Character IDs follow ascending character order, starting from `0`.
- Repeated occurrences of a character receive the same ID.
- The encoded text is represented as a one-dimensional PyTorch tensor with integer dtype `torch.long`.
- The training portion contains the requested fraction of encoded characters, rounded down to a whole number.
- The validation portion contains all remaining encoded characters.
- Character order is preserved in both portions.
- The function returns the training portion followed by the validation portion.
- `text` is non-empty and `train_fraction` is greater than `0` and less than `1`.

## Learning Objectives

- Represent text as character-level integer data.
- Build a deterministic character vocabulary.
- Prepare sequential data for language-model training and validation.
- Work with integer tensors in PyTorch.

## Examples

For the text `"banana"` and a training fraction of `0.5`, the two returned tensors contain three encoded characters each.

## Complexity Discussion

For text containing `n` characters and `v` distinct characters:

- Time complexity: `O(n + v log v)`
- Space complexity: `O(n + v)`
