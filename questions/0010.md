# 0010 PyTorch Autograd Gradient

## Problem

Compute a gradient with PyTorch autograd.

```python
def compute_gradient():
```

Use this computation graph:

```text
x = [1, 2]
a = 2x
b = a^2
c = 5 + b
```

The function should return the gradient of `c` with respect to `x` when the upstream gradient is `[1, 1]`.

## Learning Objectives

- Work with tensors that track gradients.
- Build a small computation graph.
- Run backpropagation on a non-scalar tensor.
- Read gradients from a tensor.

## Examples

```python
gradient = compute_gradient()
```

The returned gradient should be a PyTorch tensor with shape `(2,)`.

## Complexity Discussion

- Time complexity: `O(1)`
- Space complexity: `O(1)`
