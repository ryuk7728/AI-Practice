# 0001 ReLU Activation

## Problem

Implement the ReLU activation function.

```python
def relu(x):
```

ReLU stands for Rectified Linear Unit. It keeps positive values unchanged and replaces negative values with zero.

Example:

```python
[-2, -1, 0, 1, 2]
```

becomes:

```python
[0, 0, 0, 1, 2]
```

## Learning Objectives

- Understand activation functions.
- Work with element-wise array transformations.

## Complexity Discussion

For an input with `n` values:

- Time complexity: `O(n)`
- Space complexity: depends on the chosen implementation
