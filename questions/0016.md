# 0016 Simple ResNet Classifier

## Problem

Create a small ResNet-style classifier in PyTorch.

```python
class ResidualBlock ...
```

```python
class ResNet ...
```

Input images have shape:

```text
(batch_size, 1, 4, 4)
```

The model should output raw logits for `2` classes.

Expected architecture:


- `ResidualBlock` operates on tensors with `4` channels.
- `ResidualBlock` contains two convolution layers named `conv1` and `conv2`.
- Both residual block convolutions preserve the number of channels.
- `ResidualBlock` uses ReLU and a residual skip connection.
- `ResNet` accepts `n_layers`.
- The first layer maps grayscale input to `4` channels.
- `ResNet` uses ReLU after the first convolutional layer.
- The remaining `n_layers - 1` layers are residual blocks.
- The convolution stack is evaluated as a single flow, with each layer receiving the output of the preceding layer.
- Spatial size should remain `4 x 4` through the convolution stack.
- The model includes flattening before the classifier.
- The classifier hidden size is `10`.
- `ResNet` uses ReLU after the classifier hidden layer.
- The final classifier layer outputs `2` raw class scores.

The shape through the residual blocks should remain compatible with the skip connections.

## Learning Objectives

- Implement a basic residual block.
- Understand why skip connections require compatible tensor shapes.
- Track channel and spatial shape through a small CNN.
- Build a configurable stack of convolutional layers.
- Build a simple classifier head after convolutional features.

## Examples

```python
model = ResNet(n_layers=3)
X = torch.randn(5, 1, 4, 4)
logits = model(X)
```

The output should have shape:

```text
(5, 2)
```

## Complexity Discussion

For a batch with `b` images and `n` layers:

- Time complexity: depends on `b`, `n`, and convolution cost
- Space complexity: depends on batch size and intermediate activations
