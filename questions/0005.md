# 0005 Linear Regression Model

## Problem

Create a minimal linear regression model class.

```python
class LinearRegression:
    def __init__(self):
        ...

    def predict(self, X):
        ...
```

A new model should start with:

```python
w = 0
b = 0
```

The `predict` method should return predictions for input `X` using the model's current weight and bias.

The input may be a scalar, Python list, or NumPy array.

## Learning Objectives

- Represent model parameters in a class.
- Understand the prediction step of a linear model.
- Work with scalar and array-shaped inputs.
- Practice a small object-oriented ML pattern.

## Examples

If:

```python
model.w = 2
model.b = 1
```

then:

```python
model.predict([1, 2, 3])
```

should produce:

```python
[3, 5, 7]
```

## Complexity Discussion

For an input with `n` values:

- Time complexity: `O(n)`
- Space complexity: depends on the chosen implementation
