# 0021 Transformer Feed-Forward Network

## Problem

Create the position-wise feed-forward component used inside a transformer block.

```python
class FeedForward:
    def __init__(self, embedding_size, dropout=0.0):
```

The module receives tensors whose final dimension is `embedding_size`.

Expected behavior:

- A learnable linear transformation expands the final dimension from `embedding_size` to `4 * embedding_size`.
- ReLU activation is applied to the expanded features.
- A second learnable linear transformation maps the features back to `embedding_size`.
- Dropout with the supplied probability is applied to the final projected result.
- The output has the same shape as the input.
- Every position and batch example is processed independently.
- Dropout is active in training mode and inactive in evaluation mode.
- Gradients propagate through the input and all learnable parameters.

## Learning Objectives

- Build the feed-forward component of a transformer.
- Expand and contract embedding features.
- Apply position-wise transformations to sequence tensors.
- Understand activation and dropout placement.

## Examples

```python
network = FeedForward(embedding_size=12, dropout=0.1)
output = network(x)
```

For an input with shape `(2, 8, 12)`, the output has shape `(2, 8, 12)`.

## Complexity Discussion

For batch size `b`, sequence length `t`, and embedding size `e`:

- Time complexity: `O(b * t * e^2)`
- Space complexity: `O(b * t * e)` excluding model parameters
