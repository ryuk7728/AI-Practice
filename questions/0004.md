# 0004 Mean Squared Error Loss

## Problem

Implement mean squared error loss.

```python
def mse_loss(y_true, y_pred):
```

The function should compare true values and predicted values with the same shape, then return the average squared difference as a scalar.

The inputs may be Python lists or NumPy arrays.

## Learning Objectives

- Understand regression loss functions.
- Compare predicted values against targets.
- Work with scalar loss values.
- Handle array-shaped inputs.

## Examples

```python
mse_loss([1, 2, 3], [1, 2, 4])
```

should return:

```python
0.3333333333333333
```

For identical inputs, the loss should be `0`.

## Complexity Discussion

For inputs with `n` total values:

- Time complexity: `O(n)`
- Space complexity: depends on the chosen implementation
