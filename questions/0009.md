# 0009 PyTorch Tensor Basics

## Problem

Create a function that demonstrates common PyTorch tensor operations.

```python
def tensor_basics(device=None):
```

The function should return a dictionary containing:

- `direct_creation`: a tensor created from the nested values `[[1, 2, 3], [4, 5, 6]]`
- `array_conversion`: a tensor created from a NumPy array containing the same values
- `sum_last_axis`: a sum over the last axis of `array_conversion` while preserving dimensions
- `random`: random values with shape `(3, 2)` sampled from the range `[0, 1)`
- `dimensions`: shape of `array_conversion`
- `element_type`: data type of `array_conversion`
- `dimension_count`: number of dimensions in `array_conversion`
- `device_before_transfer`: device of `array_conversion` before transfer
- `transferred`: `array_conversion` transferred to the requested device
- `array_output`: `transferred` converted back to a NumPy array after moving to CPU if needed
- `float_tensor`: `array_conversion` converted to floating point dtype

If `device` is not provided, use `"cuda"` when CUDA is available, otherwise `"cpu"`.

## Learning Objectives

- Create PyTorch tensors.
- Convert between NumPy arrays and tensors.
- Inspect tensor metadata.
- Move tensors between devices.
- Convert tensor dtype.

## Examples

```python
results = tensor_basics()
```

The returned dictionary should expose the listed tensor values and metadata.

## Complexity Discussion

For the fixed tensors used in this exercise:

- Time complexity: `O(1)`
- Space complexity: `O(1)`
