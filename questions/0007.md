# 0007 Train Linear Regression

## Problem

Implement a training function for a linear regression model.

```python
def train(model, X_train, y_train, X_test, y_test, learning_rate=0.003, epochs=1000):
```

Helper code is available in:

```python
helpers/q0007.py
```

It provides:

```python
LinearRegression
mse_loss
```

The training function should update the model's `w` and `b` parameters over multiple epochs and return a list of loss values.

Expected behavior:

- The returned losses list has one value per epoch.
- Loss values are computed on the test set.
- Model parameters are updated using the training set.
- The function works with column-shaped NumPy arrays.
- The model passed into the function is modified in place.

## Learning Objectives

- Implement a basic training loop.
- Use existing helper functions and model classes.
- Track loss across epochs.
- Update model parameters during optimization.
- Separate training data from test loss evaluation.

## Examples

```python
from helpers.q0007 import LinearRegression
from solutions.q0007 import train

model = LinearRegression()
losses = train(model, X_train, y_train, X_test, y_test, epochs=100)
```

After training, the model's parameters should no longer be at their initial values for a non-trivial dataset.

## Complexity Discussion

For `n` training examples and `e` epochs:

- Time complexity: `O(e * n)`
- Space complexity: `O(e)` for the returned loss history
