# 0025 GPT Parameter Initialization

## Problem

Initialize the learnable parameters of a supplied PyTorch model using GPT-style initialization.

```python
def initialize_gpt_weights(model, std=0.02):
```

Expected behavior:

- Every linear-layer weight is replaced with values drawn from a normal distribution with mean `0` and standard deviation `std`.
- Every embedding-layer weight follows the same distribution.
- Every linear-layer bias is set to `0` when present.
- Eligible layers are initialized throughout nested model structures.
- Parameters belonging to other layer types remain unchanged.
- Linear layers without a bias are supported.
- The supplied model is returned after initialization.

## Learning Objectives

- Apply custom initialization across a nested PyTorch model.
- Initialize weights from a controlled distribution.
- Initialize weights and biases according to layer type.
- Preserve parameters outside the initialization policy.

## Examples

```python
model = initialize_gpt_weights(model)
```

## Complexity Discussion

For `p` initialized parameter values:

- Time complexity: `O(p)`
- Additional space complexity: `O(1)`
