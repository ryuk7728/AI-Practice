# 0024 Autoregressive Token Generation

## Problem

Generate additional token IDs from a causal language model.

```python
def generate_tokens(model, token_ids, max_new_tokens, context_size):
```

The model accepts a two-dimensional tensor of token IDs and returns vocabulary scores followed by an optional loss. Its score tensor has shape `(batch_size, sequence_length, vocab_size)`.

Expected behavior:

- Generation begins with the supplied token IDs.
- Exactly one new token is generated for every batch example during each generation step.
- Each model call receives no more than the most recent `context_size` tokens.
- Only the vocabulary scores at the final sequence position are used to select the next token.
- The final-position scores are converted into a probability distribution.
- Next tokens are sampled from that distribution rather than chosen deterministically.
- Each sampled token is appended to its corresponding sequence before the next step.
- The result contains the original sequence followed by exactly `max_new_tokens` generated tokens.
- Batch size, integer dtype, and device are preserved.
- If `max_new_tokens` is `0`, the original token values are returned without evaluating the model.

## Learning Objectives

- Implement autoregressive token generation.
- Maintain a bounded model context while growing a sequence.
- Convert vocabulary scores into sampling probabilities.
- Sample and append one next token per batch example.

## Examples

```python
generated = generate_tokens(
    model,
    token_ids,
    max_new_tokens=20,
    context_size=16,
)
```

If the input has shape `(3, 5)`, the returned tensor has shape `(3, 25)`.

## Complexity Discussion

For batch size `b`, context size `c`, generated-token count `g`, and vocabulary size `v`:

- Time complexity: depends on `g` model evaluations over contexts of at most length `c`
- Additional space complexity: `O(b * g + b * v)` excluding model activations
