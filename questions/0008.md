# 0008 PyTorch Device Selection

## Problem

Inspect the available PyTorch device and return device information.

```python
def get_device_info():
```

The function should return a dictionary with:

- `cuda_available`: whether CUDA is available
- `device`: `"cuda"` when CUDA is available, otherwise `"cpu"`
- `device_name`: the CUDA device name when CUDA is available, otherwise `"cpu"`

## Learning Objectives

- Check CUDA availability in PyTorch.
- Choose a device for tensor and model work.
- Return device metadata in a structured form.

## Examples

```python
info = get_device_info()
```

On a CPU-only machine, `info["device"]` should be `"cpu"`.

## Complexity Discussion

- Time complexity: `O(1)`
- Space complexity: `O(1)`
