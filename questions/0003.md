# 0003 Cross Entropy Loss

## Problem

Implement categorical cross entropy loss.

```python
def cross_entropy(y_true, y_pred):
```

Assumptions:

- `y_true` is one-hot encoded.
- `y_pred` contains probabilities.
- Each row represents one example.

The function should return the mean loss across the batch.

The result should remain finite even when predicted probabilities contain `0`.

## Learning Objectives

- Work with probability distributions.
- Understand classification losses.
- Reason about numerical stability in loss functions.

## Examples

If the true class probability is high, the loss should be small:

```python
y_true = [[1, 0, 0]]
y_pred = [[0.8, 0.1, 0.1]]
```

The loss is:

```python
-log(0.8)
```

## Complexity Discussion

For `n` examples and `c` classes:

- Time complexity: `O(n * c)`
- Space complexity: depends on the chosen implementation
