# 0006 Housing Data Preprocessing

## Problem

Load and preprocess a housing dataset.

```python
def load_data(path):
```

The CSV file contains:

- `area`
- `price`

The function should return:

```python
X_train, X_test, y_train, y_test
```

Expected behavior:

- `X` contains the `area` column as a 2D array.
- `y` contains the `price` column as a 2D array.
- The data is split into train and test sets with an 80/20 split.
- The split is deterministic with random state `42`.
- Training features are standardized.
- Test features are standardized using the training feature statistics.
- Training and test targets must be log-transformed.

Use `data/Housing.csv` for local practice.

## Learning Objectives

- Load tabular data from a CSV file.
- Separate features and targets.
- Create deterministic train/test splits.
- Apply feature scaling without leaking test-set statistics.
- Transform regression targets.

## Examples

```python
X_train, X_test, y_train, y_test = load_data("data/Housing.csv")
```

For the included dataset, the function should return four 2D arrays.

## Complexity Discussion

For a dataset with `n` rows:

- Time complexity: `O(n)`
- Space complexity: `O(n)`
