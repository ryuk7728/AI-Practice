# 0022 Pre-Norm Transformer Block

## Problem

Create a transformer block that combines causal multi-head self-attention and position-wise feed-forward computation.

```python
class Block:
    def __init__(
        self,
        embedding_size,
        num_heads,
        context_size,
        dropout=0.0,
    ):
```

The required attention and feed-forward components are provided in:

```text
helpers/q0022.py
```

The module receives tensors with shape:

```text
(batch_size, sequence_length, embedding_size)
```

Expected behavior:

- `embedding_size` is divisible by `num_heads`.
- Each attention head uses `embedding_size // num_heads` features.
- The block contains two independent normalization stages over the embedding dimension.
- The input is normalized before causal multi-head self-attention.
- The attention result is added to the original input through a residual connection.
- The result of the first residual connection is normalized before feed-forward computation.
- The feed-forward result is added through a second residual connection.
- The supplied dropout probability is used by both provided components.
- The output has the same shape as the input.
- Causal behavior and batch independence are preserved.
- Gradients propagate through the input and all learnable parameters.

## Learning Objectives

- Compose the main components of a transformer block.
- Understand pre-normalization.
- Apply residual connections around attention and feed-forward computation.
- Track tensor flow through a transformer block.

## Examples

```python
block = Block(
    embedding_size=12,
    num_heads=3,
    context_size=16,
    dropout=0.1,
)
output = block(x)
```

For an input with shape `(2, 8, 12)`, the output has shape `(2, 8, 12)`.

## Complexity Discussion

For batch size `b`, sequence length `t`, and embedding size `e`:

- Time complexity: `O(b * t^2 * e + b * t * e^2)`
- Space complexity: `O(b * t^2 + b * t * e)`
