# 0013 PyTorch Two-Layer Classifier

## Problem

Create a PyTorch neural network class for MNIST-style classification.


Expected architecture:

- Name the class `PranayNet`.
- The first fully connected layer is named `fc1`.
- `fc1` maps `784` input features to `10` hidden features.
- The second fully connected layer is named `fc2`.
- `fc2` maps `10` hidden features to `10` output scores.
- The forward pass applies a ReLU activation between the two fully connected layers.
- The forward pass returns raw class scores.

This model is intended to be trained later with cross entropy loss. The output should therefore be class scores, not normalized probabilities.

## Learning Objectives

- Define a PyTorch model class.
- Register fully connected layers.
- Implement a forward pass.
- Distinguish raw model scores from probabilities.

## Examples

```python
model = PranayNet()
outputs = model(X)
```

For an input batch with shape `(batch_size, 784)`, the output should have shape `(batch_size, 10)`.

## Complexity Discussion

For a batch with `b` examples:

- Time complexity: `O(b)`
- Space complexity: depends on batch size and layer activations
