# 0020 Multi-Head Causal Self-Attention

## Problem

Create a PyTorch module that combines multiple causal self-attention heads.

```python
class MultiHeadAttention:
    def __init__(
        self,
        embedding_size,
        num_heads,
        head_size,
        context_size,
        dropout=0.0,
    ):
```

A single-head attention module is provided in:

```text
helpers/q0020.py
```

The module receives tensors with shape:

```text
(batch_size, sequence_length, embedding_size)
```

Expected behavior:

- The module contains `num_heads` independent instances of the provided attention head.
- Every head receives the same input tensor.
- Each head produces `head_size` output features per sequence position.
- All head results are combined along their feature dimension.
- A learnable linear output projection maps the combined features back to `embedding_size`.
- Dropout with the supplied probability is applied to the projected result.
- The output has shape `(batch_size, sequence_length, embedding_size)`.
- Batch examples remain independent and causal behavior is preserved.
- Dropout is active in training mode and inactive in evaluation mode.
- Gradients propagate through the input and all learnable parameters.

## Learning Objectives

- Combine several self-attention heads into one module.
- Understand parallel attention over a shared input.
- Track feature dimensions through multi-head attention.
- Project combined attention features back to the embedding dimension.

## Examples

```python
attention = MultiHeadAttention(
    embedding_size=12,
    num_heads=3,
    head_size=4,
    context_size=16,
    dropout=0.1,
)
output = attention(x)
```

For an input with shape `(2, 8, 12)`, the output has shape `(2, 8, 12)`.

## Complexity Discussion

For batch size `b`, sequence length `t`, embedding size `e`, head size `h`, and `n` heads:

- Time complexity: `O(n * b * t * e * h + n * b * t^2 * h)`
- Space complexity: `O(n * b * t^2 + n * b * t * h)`
