# 0018 Character Sequence Batch Sampling

## Problem

Create training batches from sequential character data.

```python
def sample_text_batch(
    train_data,
    val_data,
    split,
    batch_size,
    block_size,
    device=None,
):
```

Expected behavior:

- `split` is either `"train"` or `"val"` and determines which data is sampled.
- Each batch row begins at an independently selected random valid position.
- Every input row contains `block_size` consecutive values from the selected data.
- Every target row contains the values immediately following the corresponding input positions, shifted forward by one position.
- Both returned tensors have shape `(batch_size, block_size)`.
- The original data type is preserved.
- Both returned tensors are placed on the requested device.
- If `device` is not provided, use CUDA when available, otherwise CPU.
- Each supplied data tensor contains at least `block_size + 1` values.
- The function returns the input batch followed by the target batch.

## Learning Objectives

- Sample fixed-length windows from sequential data.
- Construct next-character prediction inputs and targets.
- Work with batched sequence tensors.
- Place tensors on an available compute device.

## Examples

```python
inputs, targets = sample_text_batch(
    train_data,
    val_data,
    split="train",
    batch_size=4,
    block_size=8,
)
```

The target at each position corresponds to the value immediately after the matching input position in the selected sequence.

## Complexity Discussion

For batch size `b` and sequence length `k`:

- Time complexity: `O(b * k)`
- Space complexity: `O(b * k)`
