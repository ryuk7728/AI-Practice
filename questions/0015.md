# 0015 PyTorch CNN Classifier

## Problem

Create a PyTorch CNN classifier for RGB images.

Input images have shape:

```text
(batch_size, 3, 128, 128)
```

The model should output raw logits for `2` classes.

Expected architecture:

- The convolution layers are named `conv1`, `conv2`, `conv3`, `conv4`, and `conv5`.
- The convolution output channel counts are `16`, `32`, `64`, `128`, and `128`.
- Each convolution stage uses convolution, batch normalization, ReLU activation, and max pooling.
- Batch normalization layers are named `bn1`, `bn2`, `bn3`, `bn4`, and `bn5`.
- The model includes dropout with probability `0.5`.
- The classifier hidden sizes are `128` and `64`.
- The final classifier layer outputs `2` raw class scores.

The spatial shape changes through the convolution stages should be handled correctly so the first fully connected layer receives the right number of input features.

## Learning Objectives

- Build a CNN classifier in PyTorch.
- Track image shape changes through convolution and pooling.
- Use batch normalization and dropout in a model.
- Connect convolutional features to fully connected layers.
- Return logits for classification.

## Examples

```python
model = PranayNet()
X = torch.randn(4, 3, 128, 128)
logits = model(X)
```

The output should have shape:

```text
(4, 2)
```

## Complexity Discussion

For a batch with `b` images:

- Time complexity: depends on batch size, image size, and convolution channel counts
- Space complexity: depends on batch size and intermediate activations
