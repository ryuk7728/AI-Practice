# 0014 PyTorch Training Loop

## Problem

Create and train a PyTorch classifier with a standard training loop.

```python
def train_classifier(train_loader, device=None, epochs=20, learning_rate=0.01):
```

Helper code is available in:

```python
helpers/q0014.py
```

It provides:

```python
TinyClassifier
make_tiny_loader
```

The function should create a model, loss function, and optimizer, then train the model for the requested number of epochs.

Expected behavior:

- If `device` is not provided, use CUDA when available, otherwise CPU.
- The model is moved to the selected device.
- Each feature batch and label batch is moved to the selected device before training.
- The model is put in training mode during each epoch.
- The optimizer state is reset before each parameter update.
- The loss is backpropagated.
- The optimizer updates the model parameters.
- The average loss for each epoch is printed.
- The function returns the trained model and a list of average epoch losses.

## Learning Objectives

- Create a PyTorch model for training.
- Use a classification loss function.
- Use an optimizer.
- Move tensors and models to a device.
- Implement a basic supervised training loop.
- Track average loss per epoch.

## Examples

```python
from helpers.q0014 import make_tiny_loader
from solutions.q0014 import train_classifier

train_loader = make_tiny_loader()
model, losses = train_classifier(train_loader, epochs=5)
```

## Complexity Discussion

For `e` epochs and `n` training examples:

- Time complexity: `O(e * n)`
- Space complexity: depends on model size and batch size
