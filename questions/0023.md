# 0023 GPT Language Model Forward Pass

## Problem

Create a character-level GPT language model and implement its forward pass.

```python
class GPTLanguageModel:
    def __init__(
        self,
        vocab_size,
        embedding_size,
        context_size,
        num_heads,
        num_layers,
        dropout=0.0,
    ):
```

A transformer block is provided in:

```text
helpers/q0023.py
```

The forward interface is:

```python
def forward(self, token_ids, targets=None):
```

Both supplied tensors have shape `(batch_size, sequence_length)` and contain integer token IDs. Sequence length does not exceed `context_size`.

Expected behavior:

- Token identity and sequence position each contribute a learned representation of size `embedding_size`.
- The two representations are combined before entering the transformer stack.
- The stack contains `num_layers` independent provided transformer blocks.
- `embedding_size` is divisible by `num_heads`.
- Every transformer block uses `embedding_size // num_heads` features per attention head.
- The transformer blocks are evaluated as one continuous flow.
- A final normalization stage is applied after the transformer stack.
- A learnable linear output stage produces one raw score for every vocabulary item.
- When `targets` is omitted, the returned scores have shape `(batch_size, sequence_length, vocab_size)` and the returned loss is `None`.
- When `targets` is provided, the returned scores have shape `(batch_size * sequence_length, vocab_size)` and the returned loss is the mean cross-entropy across all positions.
- Causal behavior and independence between batch examples are preserved.
- Gradients propagate through the input-dependent model parameters.
- The model returns the scores followed by the optional loss.

Custom parameter initialization and text generation are outside the scope of this question.

## Learning Objectives

- Combine token and positional representations.
- Build a configurable stack of transformer blocks.
- Produce next-token scores over a vocabulary.
- Compute language-model loss across batches and sequence positions.

## Examples

```python
model = GPTLanguageModel(
    vocab_size=40,
    embedding_size=12,
    context_size=16,
    num_heads=3,
    num_layers=4,
    dropout=0.1,
)
scores, loss = model(token_ids, targets)
```

## Complexity Discussion

For batch size `b`, sequence length `t`, embedding size `e`, vocabulary size `v`, and `l` transformer blocks:

- Time complexity: `O(l * (b * t^2 * e + b * t * e^2) + b * t * e * v)`
- Space complexity: `O(l * b * t^2 + b * t * e + b * t * v)`
